# Python Keywords Extension for TurboWarp

A custom extension for TurboWarp that brings native Python syntax and logical keywords into the block-based programming world. Perfect for Python beginners learning through Scratch!

## ✨ Features

This extension provides a complete set of Python logic and flow-control blocks:
- **Constants**: `None`, `True`, `False`
- **Logical Operators**: `and`, `or`, `not`, `in`
- **Flow Control (C-Blocks)**: `if`, `if-else`, `if-elif-else`
- **Loops (C-Blocks)**: `for [var] in range()`, `while`
- **Misc**: `pass`

It also includes a dynamic toggle button to expand advanced Python blocks seamlessly!

## 🚀 Installation & Usage

1. Download the `python-keywords.js` file from this repository (or from the Releases).
2. Open **TurboWarp Desktop** (or TurboWarp Web).
3. Click on "Add Extension" -> "Load Custom Extension" (or drag and drop the file).
4. **⚠️ IMPORTANT: You MUST turn OFF Sandbox Mode in TurboWarp settings!** (File -> Settings -> Uncheck "Sandbox Mode").
5. Load the extension and enjoy coding!

## ⚠️ Compatibility Warning

- **TurboWarp Only**: This extension uses TurboWarp-exclusive APIs (such as `Scratch.BlockType.CONDITIONAL` for C-Blocks and dynamic UI refreshing). **It will CRASH if loaded in the official Scratch (scratch.mit.edu).**
- **Infinite Loops**: Be careful with the `while` block. Make sure your condition eventually becomes `false`, otherwise, your project will freeze!
